== Description ==

[![WordPress](https://img.shields.io/badge/WordPress-View%20Plugin-21759B?logo=wordpress&logoColor=white)](https://wordpress.org/plugins/kashida-video-embed/) [![Kashida](https://img.shields.io/badge/Kashida-View%20Plugin-6C4CF1)](https://kashida.ly/wp-plugins/kashida-video-embed/)

Kashida Video Embed helps WordPress site editors embed videos using supported share URLs or provider embed code. It includes a searchable video library, shortcode generation, a Gutenberg block, responsive player display, aspect-ratio settings, and direct video file playback.

Supported sources include YouTube, Vimeo, Facebook, X/Twitter, Dailymotion, TikTok, Twitch, Instagram, and WordPress.tv when embedding is available. Supported direct video files include MP4, WebM, and OGV, including files from the WordPress Media Library.

Some providers restrict third-party embedding, require authentication, or change their embed APIs. Dailymotion may require a valid Player ID or official embed code. Twitch requires HTTPS and a matching parent domain. Some short links may need to be replaced with the canonical video URL.

== Features ==

* Save and manage videos in a searchable library.
* Embed using a public share URL or supported provider iframe code.
* Use a shortcode or Gutenberg block.
* Create reusable collections with Grid, List, Carousel, Slider, and Featured + Playlist layouts.
* Configure responsive columns, visibility, colors, spacing, borders, slider height, autoplay, and playlist appearance according to the selected layout.
* Preview collection styling before saving. Actual playback and metadata remain controlled by the source provider.
* Arabic translation files are included.
* Use the built-in Help section for usage guidance.

== Installation ==

1. Upload the plugin ZIP through Plugins > Add New Plugin > Upload Plugin.
2. Activate Kashida Video Embed.
3. Open Kashida Video Embed > Add New and paste a supported video URL or provider embed code.
4. Save the video. To create a collection, open Video Collections, select videos, configure the display, and generate the shortcode.
5. Insert the generated shortcode in a page, post, or compatible shortcode area.

== Shortcode ==

For a saved video:

[kashida_video_embed id="123"]

Or use a supported URL directly:

[kashida_video_embed url="https://youtu.be/VIDEO_ID" ratio="16:9"]

For a saved collection, use the shortcode generated by the plugin interface.

== Privacy ==

The plugin does not send analytics or video data to Kashida. Embedded third-party players may connect to their providers when a visitor loads the page. The provider's privacy policy and embedding behavior apply.

== Frequently Asked Questions ==

= Can every video URL be embedded? =

No. Providers may restrict embedding, require login, or disable external playback. Use a supported URL or the official embed code where available.

= Why does Twitch fail on a local site? =

Twitch requires HTTPS and a matching parent domain. Local development domains or nested iframe policies can prevent playback. Test on the actual public site.

= Why does Dailymotion playback fail? =

Check that the required Player ID is configured, or use the official embed code if required by the provider's current embedding endpoint.

= Does the plugin track visitors? =

The plugin does not send analytics or video data to Kashida. Third-party players may connect to their own providers when loaded.
