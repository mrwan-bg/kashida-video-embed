Embed, organize, and display videos on WordPress with a searchable video library, five collection layouts, shortcodes, and a Gutenberg block.

== Description ==
Kashida Video Embed is a WordPress video embedding and management plugin that helps you add videos to your website using a video share URL or supported provider iframe code. Instead of manually preparing embed markup for every video, you can save videos in your WordPress dashboard, manage them in one place, and display them individually or as reusable video collections.

The plugin includes a video library, individual video shortcodes, a Gutenberg block, and a visual collection designer. Build video sections that match your website using five display layouts: Grid, List, Carousel, Slider, and Featured Video + Playlist. Configure the appearance of each collection, preview the result, and publish it using the generated collection shortcode.

Kashida Video Embed is designed for flexible presentation across screen sizes. Depending on the selected layout, you can adjust item counts, spacing, colors, overlays, borders, image fit, navigation controls, autoplay, and playlist presentation. Individual video settings also let you control the aspect ratio, player controls, lazy loading, display mode, and supported provider embed code.

Supported sources include YouTube, Vimeo, Facebook, X (Twitter), Dailymotion, TikTok, Twitch, Instagram, and WordPress.tv when embedding is available. The plugin can also play supported direct video files such as MP4, WebM, OGV, and OGG.

Video playback and embedding availability depend on each provider. Some providers restrict third-party embedding, require authentication or additional configuration, or change their embed APIs. For example, Dailymotion's current iframe endpoint requires a valid Player ID, while Twitch requires HTTPS and a matching parent domain. When a share link cannot be embedded, use the canonical video URL or the provider's official embed code where supported.

The plugin interface is translation-ready and includes Arabic PO and compiled MO translation catalogs.

**Key Features**

* **Centralized video library:** Add, edit, search, sort, and manage saved videos from the WordPress dashboard.
* **URL-based embedding:** Add a video using its public share URL instead of manually creating embed markup.
* **Provider embed code:** Use supported provider iframe code when a standard share URL is not sufficient.
* **Multiple publishing methods:** Display saved videos with a shortcode or add videos through the Gutenberg block.
* **Five collection layouts:** Choose Grid, List, Carousel, Slider, or Featured Video + Playlist to suit the content and page design.
* **Reusable video collections:** Create and edit saved collections, then publish them with a stable collection shortcode.
* **Visual collection designer:** Configure collection settings in the dashboard, preview the design, and generate or reuse the collection shortcode.
* **Layout-specific customization:** Adjust responsive item counts, spacing, card and background colors, text colors, overlays, border radius, image fit, slider height, arrows, pagination dots, and autoplay where supported.
* **Playlist presentation controls:** Configure playlist height, scrolling, active-item color, border and icon colors, and metadata visibility in Featured Video + Playlist.
* **Per-video player settings:** Control aspect ratio, player controls, lazy loading, display mode, and supported provider embed code for each video.
* **Direct video file playback:** Play supported MP4, WebM, OGV, and OGG video files.
* **Translation-ready interface:** Arabic PO and compiled MO catalogs are included.

== Source code ==

The collection generator JavaScript is maintained as readable source in `assets/src/collection-generator.js`. The browser-loaded file is `assets/collection-generator.js`; both files are currently identical. There is no minification or build step required to update this script.

== Installation ==
1. Upload the plugin ZIP through Plugins > Add New > Upload Plugin.
2. Activate Kashida Video Embed.
3. Open Kashida Video Embed > Add New and paste a video URL or provider embed code.
4. Save, then copy the shortcode from All Videos.

== Shortcodes ==

Display one saved video by its library entry ID:
[kashida_video_embed id="123"]

Or embed a supported URL directly:
[kashida_video_embed url="https://youtu.be/VIDEO_ID" ratio="16:9"]

Supported single-video attributes:
* `id` — saved video entry ID.
* `url` — public provider URL or direct video file URL.
* `ratio` — `16:9`, `9:16`, `4:3` or `1:1`.
* `controls` — `yes` or `no`.
* `lazy` — `yes` or `no`.
* `display` — `player` or `provider`.

Display selected saved video IDs in a collection layout:
[kashida_video_gallery ids="123,124,125" layout="grid"]

Display a saved collection created in the collection designer:
[kashida_video_collection id="1"]

The gallery shortcode supports `grid`, `list`, `carousel`, `slider` and `featured_playlist` layouts. Collection designer output is available through the saved collection shortcode.

== External services ==

The plugin does not send analytics, advertising identifiers, visitor profiles or video-library data to Kashida. It does not load a remote Kashida tracking service.

External connections occur only for content and providers selected by the site owner:

* **X (formerly Twitter):** When an X post is embedded, the WordPress site may request the public post URL from X's oEmbed endpoint at `publish.twitter.com` to retrieve embed markup. For supported video-only rendering, the site may request the public post ID from `cdn.syndication.twimg.com` to retrieve public video variants. These are server-to-server requests initiated while rendering the video; the post URL or ID is sent and the response is cached. If the X post embed is displayed, the visitor's browser may load X's widgets script and connect to X. X may receive standard request data such as IP address, browser information and referrer, and may use cookies or similar technologies. Terms: https://x.com/en/tos . Privacy: https://x.com/en/privacy .
* **TikTok:** TikTok content is rendered using TikTok's official player iframe. When a visitor loads the player, the browser connects to TikTok and sends the player/content identifier and standard connection data such as IP address, browser information and referrer. TikTok may use cookies or similar technologies. Terms: https://www.tiktok.com/legal/terms-of-service . Privacy: https://www.tiktok.com/legal/privacy-policy .
* **Twitch:** Twitch videos and clips are rendered using Twitch's player iframe. The embed URL includes the content identifier and the parent hostname required by Twitch. When the player loads, the browser connects to Twitch and sends standard connection data, including IP address, browser information, referrer and the embedding site's hostname. Twitch may use cookies or similar technologies. Terms: https://www.twitch.tv/p/legal/terms-of-service/ . Privacy: https://www.twitch.tv/p/legal/privacy-notice/ .
* **YouTube, Vimeo, Facebook, Instagram, Dailymotion and WordPress.tv:** Depending on the URL and provider support, the plugin creates a provider iframe URL or asks WordPress oEmbed to retrieve embed markup. The visitor's browser connects to the selected provider when its player/embed loads. An oEmbed request, when used, is made by the WordPress site to the provider and includes the public video URL. Providers may receive standard connection data and apply their own cookies or similar technologies. Terms and privacy policies: YouTube https://www.youtube.com/t/terms and https://policies.google.com/privacy ; Vimeo https://vimeo.com/terms and https://vimeo.com/privacy ; Facebook/Instagram https://www.facebook.com/terms.php and https://www.facebook.com/privacy/policy/ ; Dailymotion https://www.dailymotion.com/legal/terms and https://www.dailymotion.com/legal/privacy ; WordPress.tv https://wordpress.tv/ .
* **Provider iframe code:** If the site owner supplies an accepted provider iframe code, the visitor's browser connects to the provider specified by that iframe. Only the supported provider domains accepted by the plugin are allowed.

The site owner chooses which providers appear by adding their video URLs or embed codes. The plugin does not load all providers on every page. Provider availability, cookies, data processing and embed restrictions are controlled by each provider and its current policies.

== Data storage and compatibility ==

Saved video records use the `kashida_video` post type. When upgrading, records stored under the previous `kve_video` post type are migrated in batches to `kashida_video`; their post IDs and metadata are preserved, so existing saved-video shortcodes continue to work. The legacy post type is not registered as an active content type. Collection settings are migrated from the previous `kve_saved_collections` option to `kashida_video_embed_saved_collections` when first read, and the previous collection ID counter is used as a migration fallback. Existing collection IDs and shortcodes are preserved. Legacy records and options are retained as migration sources and are not deleted.

== Privacy ==
The plugin does not send analytics or visitor data to Kashida. Third-party video providers may receive the video URL or identifier and standard connection data when their embed/player is loaded. See the External services section above for details.

== Frequently Asked Questions ==

= Why does Twitch fail on a local site? =
Twitch requires HTTPS and a matching parent domain. Local development domains or nested iframe policies can prevent playback. Test on the actual public site.

= Can every video URL be embedded? =
No. Providers may restrict embedding, require login, or disable external playback. Use the official embed code where available.

= Does the plugin track visitors? =
The plugin does not send analytics or video data to Kashida. Third-party players connect to their providers when loaded.
